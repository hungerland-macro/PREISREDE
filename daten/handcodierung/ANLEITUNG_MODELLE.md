# Blinde Modellprüfung der 54 Stellen: Anleitung für Dumme

1. Öffnen Sie `prompt_modelle.md` und kopieren Sie den gesamten Inhalt (Strg+A, Strg+C).
2. Öffnen Sie einen neuen, leeren Chat bei Gemini, einen bei ChatGPT und einen bei Claude im Inkognito-Tab (ohne Projekt, ohne frühere Chats).
3. Fügen Sie in jeden Chat den kopierten Text ein und senden Sie ihn ab. Schreiben Sie nichts dazu.
4. Jedes Modell antwortet mit einem Kasten voller Zeilen, die mit `id;kategorie;...` beginnen.
5. Kopieren Sie jede Antwort und schicken Sie sie mir in diesen Chat, mit dem Namen des Modells davor.
